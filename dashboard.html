Dos reevaluaciones distintas (Decreto 170/2009):
FUR — Reevaluación anual: cada año, al cierre del año escolar, para todos los estudiantes PIE.
FUDEI — Evaluación diagnóstica integral: cada 2 años (NEE transitorias) o 3 a 5 años (NEE permanentes; Discapacidad Intelectual leve/moderada cada 2 años).
Las fechas "cada X año(s)" corresponden al ciclo FUDEI; el FUR es siempre anual.

* Excepción: la Discapacidad Intelectual leve y moderada se reevalúa cada 2 años, aunque sea permanente.
El ciclo cuenta desde el año de ingreso al PIE. Las transitorias que siguen un 3er año se tratan como "Nuevo Ingreso" (FUDEI completo). Un cambio de diagnóstico siempre exige crear un FUDEI nuevo.
Además, el FUR (reevaluación anual) se realiza cada año para todos los estudiantes PIE.
